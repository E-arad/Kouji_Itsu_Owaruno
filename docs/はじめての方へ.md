# はじめての方へ

プログラミングをしたことがない方向けの導入手順です。Windows を想定しています。
所要時間はおよそ15分です。

やることは3つだけです。

1. Python を入れる
2. 黒い画面（ターミナル）を開く
3. 命令を2行打つ

---

## 1. Python を入れる

<https://www.python.org/downloads/> を開き、大きな黄色いボタン
**「Download Python 3.x.x」** を押します。ダウンロードされたファイルを開くと
インストーラが起動します。

> ### ⚠️ ここが最重要です
>
> インストーラの最初の画面の**一番下**に
> **「Add python.exe to PATH」** というチェックボックスがあります。
> **必ずチェックを入れてから**「Install Now」を押してください。
>
> ここを忘れると、次の手順で「python は認識されていません」と言われます。
> その場合はインストーラをもう一度動かし、「Modify」からやり直せます。

「Setup was successful」と出れば完了です。

---

## 2. ターミナルを開く

キーボードの **Windows キー**を押し、`powershell` と打って
**Windows PowerShell** を開きます。

黒か青の画面に `PS C:\Users\あなたの名前>` のような行が出ます。
これが「命令を打ち込む場所」です。

まず、Python がちゃんと入ったか確かめます。次の1行を打って **Enter**:

```
python --version
```

`Python 3.13.1` のようにバージョンが表示されれば成功です。

> **`python は認識されていません` と出たら** — 手順1のチェックを忘れています。
> PowerShell を閉じ、Python のインストーラをもう一度動かして
> 「Add python.exe to PATH」にチェックを入れ直してください。
> やり直したあとは PowerShell を開き直す必要があります。

---

## 3. ソフトを入れる

次の1行を打って **Enter**:

```
pip install https://github.com/E-arad/Kouji_Itsu_Owaruno/archive/refs/heads/main.zip
```

文字がたくさん流れます。1〜3分ほどかかります。
最後に `Successfully installed ...` と出れば成功です。

この1行で、必要なもの（計算用の部品など）がまとめて入ります。
個別に何かを入れる必要はありません。

> **すでに Python を他のことに使っている方へ** — 上の命令は、お使いの
> numpy などが古い場合に新しい版へ更新することがあります。他のプログラムに
> 影響を出したくない場合は、かわりに次の方法をお使いください。
>
> ```
> python -m pip install --user pipx
> python -m pipx ensurepath
> ```
>
> ここで PowerShell を一度閉じて開き直し、
>
> ```
> pipx install https://github.com/E-arad/Kouji_Itsu_Owaruno/archive/refs/heads/main.zip
> ```
>
> pipx はこのソフト専用の置き場所を作るので、既存の環境には一切触れません。

---

## 4. 動かす

```
kouji
```

これだけです。しばらく待つと「徒歩での最短経路」という
ウィンドウが開きます。

> **`kouji は認識されていません` と出たら** — かわりにこちらを打ってください。
> どちらも同じものが動きます。
>
> ```
> python -m Kouji_Itsu_Owaruno
> ```

---

## 使い方

1. 必ず右上の天気を確認して、雨や雪で利用できる日か否かを確認してください。悪天候のときは絶対利用しないでください。
2. 次に、地図の上で、**出発したい場所をクリック** → 青い丸が付きます
3. 最後に、**丸で表示した神大正門をクリック** → 緑の丸が付き、黄色い線で道順が出ます

道の上を正確にクリックする必要はありません。近くの道に自動的に合わせます。

| ボタン | はたらき |
|---|---|
| リセット | 線と丸を消してやり直す |
| 天気 | 今の天気を表示（インターネットが必要） |
| 拡大 + / 縮小 − | 地図の大きさを変える（マウスのホイールでも可） |

## 困ったときは

**`pip は認識されていません`**
Python は入っているのに pip だけ動かない場合、次の形で打ってください。

```
python -m pip install https://github.com/E-arad/Kouji_Itsu_Owaruno/archive/refs/heads/main.zip
```

**赤い文字がたくさん出てインストールが失敗する**
インターネットに接続されているか確認してください。社内ネットワークなどで
外部への接続が制限されている場合、インストールできないことがあります。

**ウィンドウが開かない・すぐ消える**
Microsoft Store 版の Python を使っていると起きることがあります。
上記の python.org から入れ直してください。

**「経路が見つかりませんでした」と出る**
選んだ2地点が道でつながっていません。「リセット」で選び直してください。

**新しい版に入れ替えたい**
同じ命令に `--upgrade` を付けて打ちます。

```
pip install --upgrade https://github.com/E-arad/Kouji_Itsu_Owaruno/archive/refs/heads/main.zip
```

**消したい**

```
pip uninstall Kouji_Itsu_Owaruno
```

## 用語のメモ

| 言葉 | 意味 |
|---|---|
| Python | このソフトが書かれているプログラミング言語。動かすのに必要 |
| PATH | 「命令の名前だけで実行できる場所」の一覧。手順1のチェックはこれの設定 |
| pip | Python 用のソフトを入れる道具。Python と一緒に入る |
| ターミナル / PowerShell | 文字で命令を打つ画面 |
